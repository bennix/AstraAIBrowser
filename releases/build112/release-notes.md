## Media discovery and downloads

- List every discovered HTTP(S) media URL with its host/path summary, media type, selectable full address, Copy URL and Download actions.
- Select HLS quality and time ranges, download fragments concurrently, retry missing fragments and merge them in source order.
- Record live streams until manual or timed stop. Media tools are included in the app.
- Show download progress and speed in an expandable downloads panel. Completed history survives application restarts.
- Retry eligible YouTube 403 failures with refreshed extraction.

## Browsing

- Preserve sign-in popup navigation and native macOS browser identity.
- Use native interfaces on ordinary sites, with strict fingerprint protection enabled per site.
- Prefer English and Chinese for web language signals and resolve the browser time zone at startup.
- Include automatic proxy selection, configurable search providers and longer AI browsing execution.

## Installation

Apple-notarized and Developer ID-signed DMG for Apple Silicon, macOS 14 or later. Open the DMG and drag Astra Browser into Applications.

This release requires manual download. The existing signed automatic-update feed remains at Build 106 because the matching signing key is unavailable. Interrupted fragment downloads can resume within the current app session. Website authentication remains dependent on the site and network.
