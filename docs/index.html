Build 48 highlights

One browser. One private workspace.

Astra combines everyday Chromium compatibility with extensions, visual AI context, and privacy controls that stay inside the app.

01

Extensions stay inside Astra

Install from the Chrome Web Store, keep extension actions visible, and run X extensions on Chromium-rendered pages without launching a separate browser window.

02

WebRTC privacy by default

Direct non-proxied WebRTC traffic is blocked. Camera and microphone requests require an explicit one-time decision.

03

Cross-surface fingerprinting defense

Astra farbles Canvas, WebGL, and WebAudio readbacks, masks precise GPU details, conceals protected local and Chinese fonts, and normalizes hardware and language signals. Build 45 preserves legitimate font styling while neutralizing measurement probes.

04

Visual AI context

Capture the exact visible browser viewport from the composer, including the current standard video frame, then review or remove its thumbnail before sending.

05

Rich technical answers

AI replies render scrollable Markdown tables, code, mathematical LaTeX, and chemistry notation, including common model-specific formula wrappers.

06

AI that can work with the page

The assistant can inspect the active tab and perform confirmed browser actions while the Chromium experience remains embedded in Astra.

07

Less waiting on YouTube

When YouTube marks playback as an ad, Astra temporarily uses 8× speed and restores your content speed afterward.

08

Video compatibility without leaving Astra

Astra keeps YouTube and X on Chromium so their extensions and page state remain attached. When Chromium cannot decode an individual X video, Astra can resolve the current authenticated stream and play it in a native in-app player without replacing or reloading the page.

09

A local second brain

Astra stores notes and completed user/AI turns in an account-scoped local vector index, mirrors them as portable Markdown, and retrieves relevant context on-device. Memory entries render Markdown, scrollable tables, and local LaTeX or chemistry formulas; one or many entries can be exported as Markdown files. Expired conversations are summarized before their source records are removed.

10

Native link and language integration

General settings can make Astra the complete HTTP and HTTPS default browser. Links from other Mac apps open in embedded Chromium tabs, and websites see the language selected for Astra's interface.

11

Your browsing history, preserved

Astra keeps browsing history in its persistent Chromium profile. Open or clear it from the native History menu and General settings, or press Command-Y to view the complete record.

Meet Astra build 48.

Build 48 keeps X and Twitter pages in Chromium so extensions such as MXGA remain attached. If Chromium cannot decode a particular X video, a Play in Astra action resolves the current authenticated stream and opens it in Astra's native media player without replacing or reloading the page. The DMG is signed with an Apple Developer ID and accepted by Apple's notarization service.
